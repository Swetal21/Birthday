# Birthday Wish for Her

A 12-slide interactive birthday story (plus a setup page):
cake and candles, five reasons, our little moments (with photos), promises,
pop the balloons (with photos), love-o-meter, catch the stars, quiz, gift box,
fortune cookie, scratch card and a typed letter.

## Run it
Open `index.html` in any browser. No install needed.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (for example `birthday-wish`).
2. Upload `index.html` and `README.md`.
3. Go to Settings > Pages, choose the `main` branch and `/ (root)`, then Save.
4. Your page link will be `https://YOUR-USERNAME.github.io/birthday-wish/`.

## Get a direct link (skips the setup page)
1. Open your page, fill in her name and details, and tap "Create direct link".
2. The page shows an ending that starts with `#d.`. Add it to the end of your page link.
   Example: `https://YOUR-USERNAME.github.io/birthday-wish/#d.eyJuIjoi...`
3. Send her that link. She goes straight to the cake.

The "Create direct link" button shows a claude.ai link by default. When hosting on GitHub, use your own page link plus the `#d.` ending.

Name only: `https://YOUR-USERNAME.github.io/birthday-wish/#Priya` (uses the default text).

## Note on photos
Photos chosen on the setup page stay only in that browser and are not part of the direct link.
To show them for everyone, embed them in `index.html` as base64 images.
