# Birthday Wish for Her

A 12-slide interactive birthday story (plus a setup page):
cake and candles, five reasons, our little moments (with photos), promises,
pop the balloons (with photos), love-o-meter, catch the stars, quiz, gift box,
fortune cookie, scratch card and a typed letter.

## Run it
Open `index.html` in any browser. No install needed.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (for example `birthday-wish`).
2. Upload `index.html` and `README.md`.
3. Go to Settings > Pages, choose the `main` branch and `/ (root)`, then Save.
4. Your link will be `https://YOUR-USERNAME.github.io/birthday-wish/`.

## Personalise
- Fill in the setup page (name, photos, memories, promises, surprise, letter) and show it on your own device.
- Or share with her name only: `https://YOUR-USERNAME.github.io/birthday-wish/#Priya`
  (uses the default text; edit the defaults inside `index.html` to change them).

## Note on photos
Photos chosen on the setup page stay only in that browser. To make them permanent for everyone,
embed them in `index.html` as base64 images.
